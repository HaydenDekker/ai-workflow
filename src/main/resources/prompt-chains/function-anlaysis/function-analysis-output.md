## output requirements

For all functions:
 - detail in human readable language.
 - assess and determine the function category type
   1. System functions
   2. Utility/Helper functions
   3. Data conversion functions
   4. Application Configuration & Lifecycle Functions
   5. Business Logic & Domain Functions
   6. Data Access Functions
   7. External Communication Functions

Output an object, detailing the results in the following format,

```json
[
	{
		"function name": String,
		"function detail": String,
		"function category: String
	}

]
```
